## 🐛 Common Issues & Solutions

### Issue 1: "Templates directory not found"

**Symptom:** Backend fails to start with error about templates

**Solution:**
```bash
# Verify templates exist
ls -la backend/code_generation/templates/rag_pipeline/python/

# If missing, templates were not created properly
# Re-run the template creation step
```

### Issue 2: "Module 'jinja2' not found"

**Symptom:** Backend crashes when generating code

**Solution:**
```bash
pip install jinja2==3.1.4
```

### Issue 3: "Cannot connect to backend API"

**Symptom:** Frontend shows connection error

**Solution:**
```bash
# Check backend is running
curl http://localhost:8000/health

# If not running, start backend:
python run_backend.py
```

### Issue 4: "Project not found" in editor

**Symptom:** Editor fails to load files

**Solution:**
- Ensure code was generated successfully first
- Check backend logs for errors
- Verify project_id matches

### Issue 5: Generated code fails to run

**Symptom:** `python main.py` fails

**Solution:**
```bash
# Check Python version
python --version  # Should be 3.11+

# Install dependencies
pip install -r requirements.txt

# Check for missing API keys
cat .env
```

## 📊 Performance Benchmarks

### Expected Performance
- **Code Generation:** < 2 seconds
- **File Tree Load:** < 100ms
- **File Content Load:** < 50ms
- **Save Operation:** < 500ms
- **ZIP Download:** < 1 second

### Measure Performance

```bash
# Time code generation
time curl -X POST http://localhost:8000/api/design/{run_id}/generate-code \
  -H "Content-Type: application/json" \
  -d '{"project_name": "test_project"}'

# Time file tree load
time curl http://localhost:8000/api/code-editor/{project_id}/tree

# Time file content load
time curl "http://localhost:8000/api/code-editor/{project_id}/file?file_path=main.py"
```
